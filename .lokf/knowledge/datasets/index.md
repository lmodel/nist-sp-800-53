# Datasets

* [nist-sp-800-53 LinkML schema](nist-sp-800-53-linkml-schema.md) - The LinkML schema of the SP 800-53 controls at Release 5.2.0, `src/nist_sp_800_53/schema/nist_sp_800_53.yaml` (schema id `https://w3id.org/lmodel/nist-sp-800-53`, version 5.2.0): eleven classes, five enums and six identifier types. Its `lokf adapt` copy `.lokf/nist-sp-800-53.yaml`, rooted on the family, the control, the control enhancement and the baseline, is the bundle's domain schema.
* [NIST's SP 800-53 catalog and baseline copies](sp-800-53-catalog-copy.md) - NIST's catalog of SP 800-53 Release 5.2.0 in the Open Security Controls Assessment Language (OSCAL), with the SP 800-53A procedures inside it, and the four SP 800-53B baseline profiles, copied with NIST's licence from usnistgov/oscal-content v1.6.0 into `src/nist_sp_800_53/schema/oscal-content/` and matched to that release by git object hash. The tests derive the whole release from them.
* [Generated artefacts](generated-artefacts.md) - What the LinkML generators and `lokf adapt` write from the schema: `project/` (JSON Schema, OWL, SHACL, ShEx, JSON-LD, GraphQL, protobuf, SQL, TypeScript, Excel and Java), the Python dataclasses and Pydantic models in `src/nist_sp_800_53/datamodel/`, `docs/schema/` and `docs/elements/`, and `.lokf/nist-sp-800-53.yaml`. None is edited by hand.
* [Test data and tests](test-data.md) - The schema's tests: sixteen valid examples and thirty-four counter-examples under `tests/data/`, `tests/test_data.py`, which holds each to the validator, `tests/test_upstream.py`, which derives Release 5.2.0 from NIST's catalog and baselines, and `tests/test_schema_rules.py`, which holds the adapt copy apart from LOKF and the slsa, github-actions, oscal, spdx and nist-sp-800-218 copies in `tests/neighbours/`.
